## v0.1 Scope

`tunex-core` v0.1 stabilizes the foundational contracts for the TuneX
ecosystem: public traits, shared types, configuration schemas, plugin registry
contracts, pipeline DAG contracts, event contracts, scheduler primitives,
runtime abstractions, memory contracts, testing utilities, and crate publishing
metadata.

This release does not include real dataset loading, tokenizer logic, training
backends, GPU execution, or distributed runtime implementations.
