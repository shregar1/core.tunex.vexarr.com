# TuneX Core Documentation

This directory documents the contracts that define TuneX Core.

Start here:

- `architecture.md` for the high-level system model.
- `memory-model.md` for ownership and zero-copy expectations.
- `plugin-system.md` for plugin metadata and registry contracts.
- `pipeline-dag.md` for graph and node semantics.
- `runtime-contracts.md` for runtime, scheduler, cancellation, and channel
  contracts.
- `error-model.md` for stable errors and diagnostics.
- `benchmarking.md` for performance proof expectations.
- `rfcs/` for design records and proposed contract changes.
